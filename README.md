# Familie Marcelis Vakantie Challenge

Mobiele GitHub Pages-app met centrale opslag via Google Sheets / Apps Script.

## Vastgelegde reisvoorwaarden
- Vertrek: zondag 9 augustus 2026
- Voorkeur terug: zondag 16 augustus 2026
- Mogelijk langer: tot 9 nachten / uiterlijk 18 augustus
- Korter mag: vanaf 5 nachten
- Budget: EUR 5.000 voor transport en overnachtingen
- Eten en uitstappen vallen buiten dit budget
- Loulou moet mee; bij vliegen moet vervoer in de cabine op de concrete vlucht toegestaan en beschikbaar zijn

## Installatie
Lees `google-apps-script/INSTALLATIE.md` en publiceer daarna de website via GitHub Pages.
